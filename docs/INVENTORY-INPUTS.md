# مدخلات المخزون والتكلفة والمرتجعات

أربع مجموعات CSV/XLSX إضافية داخل الاستيراد الحالي وبوابة canonical_json_v1:

- stock_snapshots: external_id,product_code,area_code,snapshot_date,quantity
- product_costs: external_id,product_code,effective_date,currency,unit_cost
- stockouts: external_id,product_code,area_code,from_date,to_date
- return_lines: external_id,return_external_id,invoice_line_external_id,quantity,amount

الكميات بوحدة المنتج الأساسية وبثلاث منازل كحد أقصى. الرصيد صفر قيمة صحيحة، والكمية السالبة مرفوضة. التكلفة لكل وحدة أساسية وبعملة مستقلة وبالدقة النقدية الحالية، ولا تعني تكلفة بضاعة مباعة أو ربحاً محاسبياً. الانقطاع فترة شاملة الطرفين ولا يستنتج من غياب المبيعات. التواريخ لا تتجاوز يوم الشركة الحالي.

سطر المرتجع مرتبط بمرتجع مالي وسطر فاتورة من المصدر والشركة نفسيهما، والاثنان يخصان نفس الفاتورة. مجموع كميات المرتجع لا يتجاوز كمية السطر المباعة، ومجموع مبالغ السطور لا يتجاوز رأس المرتجع. سطور المرتجع لا تضيف المبلغ مرة ثانية إلى مؤشرات المبيعات. لا يتم تحريك مخزون فعلي أو تعديل سجلات إنتاجية.

الاستيراد إضافة فقط بمعرّفات مستقلة ضمن الشركة والمصدر والنوع. يعاد الفحص عند الاعتماد داخل قفل الشركة، ويحفظ أصل الدفعة المشفر. تستخدم الصلاحيات المالية الحالية data.sales.import وdata.import.manage وdata.sensitive.read. شاشة التحليل تعرض السجلات بصفحات مستقرة. القوالب الجديدة تختفي قبل ترحيل 2026_10_07_000004_create_inventory_observations.php والمسار الجديد يرجع 503.

الحدود: ليست دفتر مخزون أو تخصيص مستودعات أو تحويل وحدات؛ يجب توحيد الوحدة قبل الاستيراد. يمكن أن تقدم مصادر متعددة معلومات متعارضة؛ يجب اختيار مصدر الحقيقة قبل التوقع. لا يُعد غياب سجل انقطاع دليلاً على توفر المنتج، ولا يُملأ الناقص بتكلفة صفر. التكاليف والأرصدة مدخلات تحليلية؛ لا يُستنتج الربح أو الطلب غير الملبى تلقائياً.

التحقق: 119 اختباراً / 1093 تأكيداً، والبناء والتنسيق ناجحة. اختبارات جديدة للدقة والصفر والكمية السالبة وتجاوز كمية البيع وقيمة المرتجع، وعدم مضاعفة المؤشرات والعزل وإعادة الفحص عند الاعتماد.
