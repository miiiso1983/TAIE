# مصدر الحقيقة وربط الهويات

سجل مراجعة بشري بإصدارات لكل نوع بيانات؛ يحتاج مصدر دفعة مستوردة لذلك النوع، إقراراً وسبباً، ومعرّف الإصدار السابق عند التغيير. latest version هو المصدر الحالي، وتبقى النسخ السابقة محفوظة. الصلاحية الجديدة advisor.source.manage مع قراءة المبيعات والبيانات الحساسة. الشاشات تعرض الدفعات المعروفة وتاريخ المراجعة ولا تجلب أسرار الأنظمة.

التوقعات الجديدة ترفض اختيار مصدر فواتير يختلف عن مصدر الحقيقة المراجع، وتحفظ الإصدار في أدلتها وبصمتها. لا يتغير تحليل محفوظ عند تغيير المصدر. قبل إنشاء سجل مصدر الحقيقة يستمر التوافق مع اختيار المصدر الصريح؛ لم تجر تصفية المؤشرات المالية القديمة أو دمج مصادر متعددة تلقائياً.

ربط الهوية يدوي لموظف أو عميل أو منتج أو فاتورة موجودة في الشركة، مع معرّف من مصدر موثق بدفعة مستوردة. يلزم أيضاً حق HR أو العملاء بحسب النوع. المعرّفات والأسباب مشفرة؛ فهرس المعرّف HMAC بمفتاح التدقيق. لا تستبدل نسخة نشطة، والتصحيح يبدأ بإيقاف موثق ثم نسخة جديدة تشير إلى معرّف السابقة، مع حفظ تاريخها. الربط لا يعدل الفواتير ولا العميل أو الموظف، ولا يطبق تلقائياً في موصل أصلي أو الاستيراد؛ اعتماد قواعد التحويل لكل موصل مطلوب قبل ذلك.

ترحيل 2026_10_07_000008_create_source_governance.php؛ المسارات الجديدة تعيد 503 قبل جهوزيته، والتوقعات السابقة تتوافق قبل وجود سجل الحوكمة. لم يطبّق على قاعدة التشغيل.

التحقق: 138 اختباراً / 1342 تأكيداً وبناء ناجح؛ حقوق الإدارة والنوع، عزل الشركات، الإصدارات والتعارض، تشفير الهوية، إيقاف وتصحيح مع حفظ التاريخ، واحترام التوقع للمصدر المختار. هذه حوكمة ومراجعة موثقة وليست إثبات مطابقة مصدر فعلي أو تكاملاً مع MaxCon.
