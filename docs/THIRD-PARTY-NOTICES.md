# Third-party interface packages

This project uses Microsoft Fluent UI React components and Fluent system icons through their npm packages:

- `@fluentui/react-components`: https://github.com/microsoft/fluentui — MIT.
- `@fluentui/react-icons`: https://github.com/microsoft/fluentui-system-icons — MIT.
- React and React DOM: https://github.com/facebook/react — MIT.

Package versions are pinned in package.json and package-lock.json. Original package license notices apply to those packages and their compiled assets. No proprietary Microsoft product branding or remote Microsoft fonts are bundled; the interface uses system fonts available on the user's device.
