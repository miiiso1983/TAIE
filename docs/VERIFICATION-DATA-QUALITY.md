# تحقق المصالحة وتفاصيل المنتجات والمناطق — 2026-10-07 (بغداد)

نجحت مجموعة Laravel كاملة: 96 اختباراً و830 تأكيداً باستخدام SQLite. تشمل الدفعة 7 اختبارات جديدة للمصالحة وتفاصيل الأعمال. نجحت مجموعة Playwright كاملة: 21 سيناريو على Chromium مع استجابات API محاكاة للواجهة، منها سيناريو إنشاء المقارنة وسيناريو محلل للقراءة على الجوال. نجح بناء Vite للإنتاج وفحص Pint للملفات المعدّلة؛ تحذير حجم Fluent لا يمنع البناء.

تغطي الاختبارات: الاستيراد والمعاينة والاعتماد، الكميات بدقة ثلاث منازل والسطور المجانية بمبلغ صفر، منع تجاوز رأس الفاتورة وإعادة التحقق عند الاعتماد، عدم مضاعفة المؤشرات، حفظ المنطقة وقت استيراد الفاتورة وعدم اختلاق موقع تاريخي بعد الربط، الفروقات الموجبة والسالبة، تشفير الأدلة، منع تكرار المقارنة عند إعادة الطلب، تغيّر البيانات ضمن نطاق المقارنة فقط، الفصل بين المصدر والعملة والفترة، دقة IQD وUSD، الفترات الفارغة دون تأكيد تغطية، صلاحيات الكتالوج والمراجعة وعزل الشركات.

اختبارات الواجهة تتحقق من اختيار المصدر والعملة بالقوائم القابلة للبحث، الإقرار المطلوب قبل الإرسال، قيم المبالغ كنصوص دون فقد دقة، عرض التفاصيل، وإتاحة المنتجات والمناطق والسطور لمحلل القراءة دون زر إنشاء، وعدم تجاوز عرض الجوال. تمت معاينة لقطة شاشة المصالحة الفعلية مع بيانات اختبار محاكاة.

لم تُنفذ اتصالات مع برامج الشركات أو مزود AI حي، ولا اختبار MySQL/Redis أو خادم الماك أو نشر إنتاجي. المقارنة الحالية للمجاميع وليست مطابقة كل سجل مع المصدر. إثبات تغطية الشركة والتوقعات والبيانات السكانية الرسمية ما زالت مراحل قادمة. تُرفع حدود استيراد الملفات أو أحجام الفحص فقط بعد تصميم الخلفية واختبارات الأداء؛ اختبارات الوحدة تعطل محدد معدل الاستيراد داخل فئة البيانات الجديدة لتجهيز حالات متعددة، ولا تغيّر معدل الإنتاج.
