# الإعداد الموجّه وفحص الترقية

صفحة «إعداد المستشار» تعرض وجود مجموعات البيانات داخل الشركة الحالية وتشرح الترتيب العملي: مصدر الحقيقة، الوحدات والمناطق، الاستيراد، مطابقة مستقلة، سياسة ومعتمدون، مراجعة بشرية وتجرِبة محدودة. وجود السجلات لا يعني قبولها أو اكتمال تغطيتها، والتقارير والقرارات تحتاج مراجعة فترة محددة. الصفحة لا تنفذ ترحيلات أو تمنح صلاحيات.

GET /api/advisor/setup يحتاج advisor.sales.read وdata.sensitive.read. لا يعرض أعداد HR أو رواتب، ولا يتجاوز حقوق التقارير والقرارات. عند غياب جدول يعرض «ينتظر ترقية النظام» بدلاً من تعطيل المسارات القديمة.

أُضيف فحص جداول وحقول الدفعات الجديدة وأسماء الصلاحيات إلى teami:launch:check. هذا الفحص لا يطبق الترقية ولا يمنح الأدوار، ولا يثبت الاستعادة أو MySQL/Redis أو قبول شركة حية. يظل إطلاق الإنتاج ممنوعاً عملياً حتى معالجة نتائج البيئة وقبولها.

قائمة سياسات المكافآت أصبحت قابلة للبحث والترقيم من الخادم، مع قراءة نسخة مختارة خارج الصفحة الحالية، بدلاً من اقتصار الاختيار على 20 نسخة محملة. يوجد اختبار تجاوز 55 سياسة وعزل نسخة شركة أخرى.

التحقق: 131 اختباراً / 1249 تأكيداً وبناء ناجح. لم تنفذ ترحيلات قاعدة الجهاز أو مزامنة صلاحياتها.
