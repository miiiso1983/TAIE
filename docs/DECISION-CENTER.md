# مركز القرارات والمتابعة

القرار إجراء بشري مرتبط بمعرّف ونسخة تقرير محفوظ، مع سبب ومسؤول نشط من نفس الشركة وموعد ومقياس ووحدة وخط بداية وهدف. لا يغيّر النظام الفواتير أو الموارد البشرية عند اعتماد الإجراء.

الحالات: مقترح ← معتمد أو مرفوض؛ معتمد ← قيد التنفيذ أو ملغى؛ قيد التنفيذ ← مكتمل أو ملغى. الحالات النهائية لا تعاد فتحها. الإكمال يتطلب قيمة فعلية بنفس الوحدة ومرجع دليل وشرح. الفرق عن خط البداية والهدف لا يثبت السببية أو عائد الاستثمار.

الصلاحيات الجديدة: advisor.decision.read وadvisor.decision.manage، إضافة إلى advisor.report.read وdata.sensitive.read وصلاحيات نوع التقرير. لا تظهر قرارات HR لقارئ المبيعات فقط. المسؤولون من عضويات الشركة النشطة. البيانات والتاريخ مشفران، والحالات تحفظ أحداثاً متتابعة وسجل تدقيق؛ version يمنع الكتابة من صفحة قديمة، وIdempotency-Key يمنع تكرار الطلب.

الترحيل: 2026_10_07_000003_create_advisor_decisions.php. التطبيق القديم يستمر قبله، والمسارات الجديدة ترجع 503. يجب منح الصلاحيات صراحة بعد ترقية البيئة؛ لم تُنفذ ترقية على قاعدة الجهاز.

التحقق: 116 اختباراً / 1033 تأكيداً؛ اختبار دورة الحالة والأدلة والتشفير والعزل وحقوق HR والتكرار وتعارض النسخ وانتظار الترقية. بناء الواجهة وPint وdiff ناجحة؛ قبول المتصفح الفعلي ما زال معلقاً على قيد Chrome السابق.
