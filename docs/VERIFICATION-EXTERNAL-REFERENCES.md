# تحقق المراجع والقوائم القابلة للبحث — 2026-10-07 (بغداد)

- نجحت اختبارات Laravel كاملة: 89 اختباراً و678 تأكيداً باستخدام SQLite.
- نجحت اختبارات Playwright كاملة: 19 سيناريو على Chromium، مع API محاكى للواجهة.
- نجح بناء Vite للإنتاج وفحص Pint للملفات المتغيرة. تحذير حجم حزمة Fluent أكبر من 500KB لا يمنع البناء؛ تحسين التقسيم ضمن أعمال الأداء.

اختبارات المراجع تغطي ملاءمة النشاط، الإقرار المطلوب، تشفير ملاحظة المراجعة، منع تكرار الإضافة والوظيفة، فصل مستندات الشركة عن المصدر الخارجي، الصلاحيات وعزل الشركات، واستبعاد المصدر الموقف من استرجاع المساعد. اختبارات RAG تستخدم مزوداً محاكياً وتفحص تمييز السياق والاستشهادات.

اختبار الواجهة يغطي البحث العربي مع التشكيل، اختيار الأسهم وEnter، الحفاظ على قيمة part_time ومعرّفات العلاقات، مسح القسم والوظيفة، تغيير النشاط دون اعتماد تلقائي، والإقرار المطلوب وإضافة المرجع وإيقافه. المجموعة الكاملة تتحقق أيضاً من مسارات HR والفوترة والاستيراد والتقارير والتكامل.

تمت معاينة شاشة المكتبة فعلياً بخط Almarai والثيم الحالي. بيانات اللقطة محاكاة. ملفات الخط والصورة المحلية موجودة رغم تحذيرات Vite عن روابطها الثابتة.

لم يُختبر مزود AI حي أو MySQL/Redis أو نشر إنتاجي أو بيانات شركة حقيقية في هذه الدفعة. الكتالوج مراجع أصلية وروابط وخلاصات محررة، وليس جلباً حياً أو نصوصاً كاملة. توجيه النموذج لفصل السياسات عن المراجع لا يضمن صحة كل إجابة؛ القبول البشري ما زال مطلوباً.
