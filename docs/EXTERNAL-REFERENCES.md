# المراجع الخارجية والقوائم القابلة للبحث — 2026-10-07 (بغداد)

## الاستخدام

افتح «المعرفة والمساعد» ثم «المراجع الخارجية والتطوير». اختر نشاط الشركة لتظهر المراجع المناسبة أولاً، وصفِّ بالمجال أو ابحث بالعنوان والناشر. النشاط يشمل العام والأدوية والمكاتب العلمية والتكنولوجيا والتجارة والتوزيع والخدمات. اقتراح الملاءمة تصنيف تحريري بسيط، وليس تقييم امتثال لكل نشاط.

تتوفر ثمانية مراجع أولية: سياسات وإجراءات حسب النشاط، وتطوير المبيعات، وإدارة الفريق والعملاء. المراجع العامة مناسبة لجميع الأنشطة؛ التخصصية مضافة للأدوية والتوزيع والتكنولوجيا. توسيع المراجع المتخصصة للتجزئة والخدمات وبقية الأنشطة ضمن الخطة، مع مراجعة كل مصدر.

«قراءة المصدر الأصلي» تفتح موقع الناشر. إضافة المرجع للمساعد تحتاج صلاحية ai.knowledge.manage وإقراراً وملاحظة مراجعة بين 12 و1000 حرف. تُشفَّر الملاحظة، وتسجَّل العملية. تغيير النشاط لا يضيف مستندات تلقائياً.

تُضاف خلاصة تحريرية موجزة فقط إلى مصدر معرفة مستقل بالشركة؛ لا يتم جلب المقال الكامل أو نسخه أو تحديثه آلياً. كل مرجع يحتفظ بالناشر والرابط وتاريخ مراجعة الخلاصة وتاريخ النشر عند توفره. تاريخ المراجعة ليس تاريخ آخر تحديث للموقع. لا يسمح برفع مستندات الشركة داخل المصدر الخارجي.

## الفهرسة والمساعد

يتطلب الاسترجاع مزود AI مهيّأ والعامل: `php artisan queue:work --queue=ai,analytics,default`. حالة الفهرسة تظهر في إدارة المعرفة. المصادر الخارجية تخضع لصلاحيات الشركة وحساسية المصدر وقائمة المصادر المسموحة للوكيل. تكرار الإضافة لا يكرر المصدر أو المستند نفسه.

تعرض استشهادات المساعد نوع المصدر وناشره ورابطه. تميّز تعليمات المساعد المراجع الخارجية عن سياسات الشركة، وتطلب التصريح بغياب السياسة الداخلية بدلاً من اختلاقها. هذا توجيه للنموذج، وليس ضماناً لصحة كل إجابة؛ يبقى القرار واعتماد السياسة للمدير. المراجع الدولية ليست القانون العراقي.

زر «إيقاف استخدامه» يستبعد المصدر من الاسترجاع اللاحق ويحفظ التاريخ؛ لا يمسح إجابات المحادثات السابقة. يمكن إعادة إضافته بعد المراجعة. تحديث الكتالوج والمحتوى ومراجعة الإصدارات أعمال تحريرية مقصودة، وليست مزامنة حية.

## القوائم المنسدلة

استُبدلت حقول الاختيار الحالية بمكوّن Fluent UI Combobox موحّد قابل للبحث، في النماذج والمرشحات وربط الأعمدة واختيار ورقة Excel. البحث يتجاهل التشكيل والتطويل وبعض اختلافات كتابة الحروف العربية. الكتابة تُصفّي الخيارات ولا ترسل نصاً حراً إلى API. الاختيار يحفظ معرّف السجل أو القيمة الأصلية، ويدعم الأسهم وEnter، والقيم الفارغة والحقول المطلوبة والتعطيل.

البحث محلي ضمن الخيارات المحمّلة؛ لا يضيف تحميل جميع موظفي الشركة أو البحث على الخادم إلى كل حقل. تحسين القوائم الكبيرة بالبحث والترقيم من الخادم مرحلة تالية.
