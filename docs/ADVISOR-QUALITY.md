# مصالحة البيانات وتأكيد التغطية — 2026-10-07

مصالحة كل عملة تستخدم الفواتير المؤرخة من `from` إلى `to`، ومعاملاتها المسجلة حتى `as_of` فقط، بما فيها تحصيلات بعد نهاية فترة الفواتير. لا تجمع USD وIQD. المعادلة: المبيعات − المرتجعات − التحصيل = الرصيد − الرصيد الدائن. التوازن الحسابي ليس دليل اكتمال أو تدقيقاً مستقلاً.

صفحة تحليل الأداء تعرض عدد الفواتير والتحصيلات والمرتجعات، فروق المصالحة، آخر تواريخ السجلات ودفعات المصدر الداعمة. عدم وجود تاريخ يعرض «بيانات غير متوفرة» وليس إثبات عدم حدوث معاملات. الفواتير دون تحصيل مسجل مؤشر نقص يحتاج مراجعة، وليس حكماً بأنها غير مدفوعة.

## تأكيد التغطية

اختر عملة واحدة واعرض التحليل، ثم أدخل أعداد ومبالغ المصدر المستقل وإقراراً وملاحظة نطاق المطابقة. لا تُملأ أرقام الإقرار تلقائياً. المبالغ نصوص صحيحة بوحدة السنت لـUSD والفلس لـIQD. يُرفض أي اختلاف أو نسخة قديمة قبل الكتابة. يسمح بإقرار مصدر صفري صريح مع بيان سبب اكتماله؛ لا يتحول غياب البيانات إلى إقرار تلقائي.

`POST /api/advisor/sales/coverage` يتطلب advisor.sales.read وdata.sensitive.read وdata.import.manage وIdempotency-Key. الحقول: from/to/as_of/currency، fingerprint من قراءة المؤشرات، acknowledge=true، source_note (12–1000 حرف)، وexpected بما فيه invoice_count/receipt_count/return_count/sales_minor/returns_minor/collected_minor. لا يسمح بتأكيد موظف واحد.

الإقرار مستقل لكل شركة وفترة وتاريخ قياس وعملة. تُشفّر ملاحظة المراجعة وأرقام المصدر؛ سجل التدقيق لا يتضمنها. تحفظ نسخة جديدة دون حذف السابقة، ويصبح أحدث إقرار changed عند تغير هوية أو قيمة المعاملات أو أدلة الفواتير. تقارير المبيعات الجديدة تحفظ المصالحة والإقرار في نسختها؛ التقارير القديمة ثابتة. تأكيد عام لكل عملة أو HR أو مستشار المكافآت ليس ضمن هذه الدفعة؛ المكافآت تستمر بطلب مراجعة مستقلة لبيانات الموظف.

## الترقية

Migration جديدة: 2026_10_07_000001. لم تطبق على قاعدة الجهاز أثناء التطوير حفاظاً على البيانات. يجب تطبيقها ضمن ترقية المشروع المعتادة بعد النسخ الاحتياطي وقبل تقديم واجهة التحليل الجديدة. لا توجد صلاحيات جديدة ولا حاجة إلى seed لهذه الدفعة. لا تنفذ migrate:fresh على قاعدة موجودة.

## الحدود المتبقية

لا تشمل المصالحة الأرصدة الافتتاحية أو الإشعارات الدائنة الأخرى أو التحويلات أو الدفعات غير المرتبطة بالفواتير المختارة. الإقرار بشري، ولا يختبر صحة المصدر الخارجي. تحديد التأخر يحتاج سياسة حداثة خاصة بالشركة؛ المعروض تواريخ فعلية ولا يفترض حد صلاحية موحداً.

## التحقق المحلي

نجح Laravel: 94 اختباراً / 716 تأكيداً، وبناء Vite وPint وفحص diff. أضيف سيناريو واجهة للمطابقة دون ملء تلقائي وبقاء المبالغ نصوصاً. محاولة Playwright لـ20 سيناريو لم تبدأ تنفيذ واجهات التطبيق: منع macOS sandbox خدمة MachPortRendezvous في Chrome وChrome Headless Shell (Permission denied 1100). تحتاج إعادة التنفيذ في بيئة تسمح بتشغيل المتصفح؛ لا نعدها اختبارات ناجحة.

قراءة المؤشرات تعمل حتى قبل تطبيق migration الجديدة؛ يتوقف تأكيد التغطية وحده برسالة ترقية وHTTP 503. اختبر هذا التوافق ضمن المجموعة.
