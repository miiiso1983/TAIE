# توسعة استرجاع المعرفة وضبط التكلفة

أزيل حد أول 5000 مقطع الذي كان قد يحجب وثائق أحدث بلا تنبيه. يفحص الاسترجاع المقاطع المؤهلة من نفس الشركة والموديل وصلاحيات حساسية المصدر ومصادر الوكيل، بصفحات 250، ويحفظ أفضل K فقط مع ترتيب ثابت عند تعادل التشابه. يبقى استبعاد النسخ المرجعية القديمة والمراجعات المنتهية والمصادر المعطلة.

AI_MAXIMUM_RETRIEVAL_SCAN الافتراضي 50000، محصور 1–100000. إذا تجاوزت المصادر المؤهلة الحد ترجع العملية 422 قبل طلب embedding، ولا تجيب من جزء صامت من المصادر. مثبت أعلى id يمنع إدراج مقاطع أحدث أثناء المرور. هذا بحث دقيق خطي محدود الذاكرة وليس فهرس ANN؛ يلزم فهرس متجه عند تجاوز الحد أو حاجة أداء أعلى. المقاطع الخارجية القديمة المؤهلة في SQL تدخل حد الفحص وإن كانت ستستبعد لاحقاً.

AI_RETRIEVAL_LIMIT محصور 1–20. AI_MAXIMUM_CONTEXT_CHARS الافتراضي 24000، محصور 1000–100000، ويمنع استدعاء LLM عند تجاوز السياق بدلاً من إرسال نص غير محدود. النصوص الطويلة تحتاج تقسيم مقاطع أصغر أو تقليل K.

AI_MAXIMUM_EMBEDDING_CHUNKS الافتراضي 1000، محصور 1–2000 للمستند. حجم المقطع محصور 300–6000. قبل أي استدعاء embedding تُرفض المستندات التي تتجاوز حد الأحرف أو عدد المقاطع المتوقع، بما فيها إعداد تداخل مبالغ فيه. المتجهات الفارغة أو غير الرقمية أو غير المتسقة الأبعاد ترفض أو تستبعد؛ استجابة مزود غير صالحة لا تنتج إجابة مختلقة. هذه حدود عمل وليست ضمان ميزانية مالية؛ الحصة ومراقبة المزود ما زالت مطلوبة.

التحقق: 129 اختباراً / 1230 تأكيداً. اختبار 5001 مقطع يجد الأفضل بعد الحد القديم؛ حد الفحص يمنع إجابة جزئية قبل أي طلب إضافي للمزود؛ ميزانية الفهرسة تمنع الاستدعاءات عند تجاوزها؛ اختبار متجه غير صالح وتعادل ثابت. توجد اختبارات عزل ومراجع وإبطال سابقة، لكن قبول جودة إجابات مزود حي وتكلفته لم ينفذ.
