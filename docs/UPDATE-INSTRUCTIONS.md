# تثبيت تحديث واجهة Microsoft Fluent UI

هذه النسخة تعدّل كود المشروع ولا تتضمن قاعدة بياناتك أو حساباتك أو ملف `.env`. توجد ترحيلات للفوترة وتشفير منع التكرار؛ نفّذ الخطوات التالية بعد النسخ الاحتياطي.

## التثبيت على المشروع الموجود

1. أوقف الخادم مؤقتاً بـ Ctrl+C في نافذة `php artisan serve`.
2. احتفظ بنسخة احتياطية من مجلد مشروعك وقاعدة بياناتك خارج المجلد.
3. فك ملف ZIP في مجلد مستقل، ثم انسخ محتويات `teami-ai-enterprise` فوق مجلد مشروعك الحالي. احتفظ بملف `.env` وقاعدة البيانات ومجلد `storage` الموجودين على جهازك. لا تستبدل المشروع كله بحذف المجلد القديم.
4. من Terminal:

```sh
cd /Users/mustafaaljaf/Documents/Codex/teami-ai-enterprise
php -v
composer install
npm ci
npm run build
php artisan optimize:clear
php artisan migrate --force
php artisan db:seed --class=DatabaseSeeder --force
php artisan teami:permissions:sync-owners
php artisan test
php artisan serve
```

ملف `composer.lock` المرفق يتطلب PHP 8.4.1 أو أحدث. لا تستخدم تجاوز متطلبات PHP عند تثبيت النسخة للتشغيل الفعلي.

5. افتح http://127.0.0.1:8000 وسجّل الدخول بحسابك الموجود، ثم حدّث المتصفح لتُحمَّل الواجهة الجديدة.

## ماذا تغيّر؟

- واجهات النظام تستخدم Microsoft Fluent UI React v9 فعلياً، مع العربية وRTL ووضع فاتح وداكن، وتنقل علوي وقائمة جوال متجاوبة ونوافذ نماذج موحّدة.
- تحتاج Node 20.19 أو أحدث لإعادة بناء الواجهة. النسخة تتضمن ملفات `public/build` الجاهزة. راجع `docs/FLUENT-UI.md` للمزيد.

- عرض الوظيفة تحت اسم الموظف، صفحة التفاصيل، تعديل البيانات والحالة والقسم والوظيفة، بحث وتصفية وترقيم صفحات.
- تقديم طلب الإجازة والموافقة أو الرفض مع ملاحظة، إضافة أنواع الإجازات وتخصيص الأرصدة وعرض المتاح.
- تظهر أدوات التعديل حسب الصلاحيات، ويتحقق الخادم من الصلاحيات والشركة لكل عملية.
- إنهاء خدمة الموظف يسجّل تاريخ الإنهاء؛ إعادة تفعيله تمسح التاريخ. تعطيل دخول حساب المستخدم ليس جزءاً من هذا الإجراء.
- مراجعة الإجازات تحتاج موظفاً نشطاً مرتبطاً بحساب المراجع في `user_id`. الحساب المالك وحده لا ينشئ هذا الربط تلقائياً.

## إعداد الذكاء الاصطناعي

الإعداد الأصلي يستخدم `AI_API_KEY`، وأصبحت النسخة تدعم أيضاً `OPENAI_API_KEY` كبديل. يُفضَّل الاسم الأصلي. اضبط في `.env` محلياً:

```dotenv
AI_API_ENDPOINT=https://api.openai.com/v1
AI_API_KEY=ضع_المفتاح_الجديد_هنا
AI_CHAT_MODEL=gpt-4o-mini
AI_EMBEDDING_MODEL=text-embedding-3-small
```

ثم شغّل `php artisan config:clear`، والعامل `php artisan queue:work --queue=ai,default` لفهرسة مستندات المعرفة. لم تُجرَ اتصالات بمزود AI أثناء تطوير هذا التحديث. لا تحتوي النسخة على مفتاح API أو حسابات تجريبية.

الوكيل الحالي يجيب من مستندات المعرفة المفهرسة؛ لا ينفذ إجراءات HR أو sales ولا يقرأ جميع سجلات الأعمال تلقائياً.
